# Security Policy

Do **not** report vulnerabilities in public issues. Report them privately through GitHub's
[Report a vulnerability](../../security/advisories/new) (Security → Advisories).

- Include the impact, steps to reproduce and the version. We usually reply with our findings within 7 days.
- Supported versions: only the latest release receives security fixes.
- Do not send files containing work data or personal information. Please reproduce with synthetic data.

---

보안 취약점은 **공개 이슈로 올리지 마세요.** GitHub의 [비공개 취약점 제보](../../security/advisories/new)로 알려 주세요.
영향 범위·재현 방법·버전을 적어 주세요(보통 7일 안에 답합니다). 최신 릴리스만 보안 수정을 받습니다.
업무 자료·개인정보가 담긴 파일은 보내지 말고 합성 자료로 재현해 주세요.
