# Contributing

- Issues and pull requests are welcome. Please discuss large changes in an issue first.
- `python -m pytest` must pass. Leave one test for any new behavior.
- Use **synthetic data** only in tests — never real organization, person or supplier names, work files or secrets.
- By contributing, you agree that your code is distributed under this repository's [MIT](LICENSE) license.
- External contributions (pull requests) are merged after maintainer review. Release signing follows the
  [Code signing policy](CODE_SIGNING.md).
